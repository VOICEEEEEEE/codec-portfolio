# ✦ LUMIÈRE — Nail & Spa Atelier

Премиальный полнофункциональный веб-сайт и CRM-система для ателье маникюра и эстетики (Патриаршие пруды, Москва).

---

## 🌟 Возможности проекта

### 1. Клиентский веб-сайт (`index.html`)
- **Интерактивный конструктор визита:**
  - Живой калькулятор стоимости и времени в зависимости от выбранных услуг.
  - Категории: Маникюр, Педикюр, Дизайн & Nail Art, SPA-ритуалы.
  - Опция «Сервис в 4 руки» (параллельно маникюр + педикюр с автоматическим пересчетом времени и наценки +15%).
- **Интерактивная галерея работ:**
  - Фильтрация по стилям: Clean Girl & Nude, Авторский Art, Микро-френч.
  - Кнопка заказа точного дизайна из портфолио прямо в модальное окно записи.
- **Онлайн-запись (Консьерж-сервис):**
  - Выбор мастера (Алина Романова, Элина Вересова, Маргарита К.).
  - Выбор даты и слота времени.
  - Маска ввода телефона (+7 ...).
  - Выбор комплиментарного напитка (Prosecco, Матча на кокосовом, Лавандовый раф, Травяной сбор).
  - Автоматическая генерация уникального кода бронирования (`LMR-XXXX`).
  - Сохранение бронирования в базу данных SQLite и `localStorage`.
- **Эстетика и анимации:**
  - Фирменная палитра: крем, золото, пудра, обсидиан.
  - Прелоадер, плавный скролл, плавное появление секций (Scroll Reveal).
  - Кнопка «Наверх», sticky mobile bottom bar для удобного оформления с мобильных.

### 2. CRM-Панель администратора (`admin.html`)
Доступна по адресу: `http://localhost:8000/admin`
- **Дашборд ключевых метрик:**
  - Всего записей, количество новых заявок, ожидаемая выручка (₽), топ-стилист.
- **Управление бронированиями:**
  - Таблица со всеми бронированиями клиентов в реальном времени.
  - Быстрый переход: звонок гостю (`tel:...`) или чат в WhatsApp (`wa.me/...`) в 1 клик.
  - Изменение статуса на лету (🟡 Новая, 🔵 Подтверждена, 🟢 Завершена, 🔴 Отменена).
  - Удаление записей.
- **Фильтрация и мгновенный поиск:**
  - Фильтры по статусам.
  - Поиск по имени, номеру телефона, коду брони или мастеру.
- **Ручное добавление записи:**
  - Модальное окно для администратора (для записи гостей по телефону или визиту).

### 3. Backend & API (`server.py` + `database.py`)
- Асинхронный сервер на базе **Starlette** и **Uvicorn**.
- База данных: **SQLite** (`lumiere.db`).
- REST API:
  - `GET /api/bookings` — получение списка всех записей (с фильтрами).
  - `POST /api/bookings` — создание новой записи.
  - `PATCH /api/bookings/{id}` — обновление статуса записи.
  - `DELETE /api/bookings/{id}` — удаление записи.
  - `GET /api/stats` — статистика для дашборда.

## 🚀 Как запустить проект

### Вариант 1. Через файл `start.bat` (Быстрый запуск)
Просто дважды кликните по файлу **`start.bat`**. Он запустит Python-сервер и откроет сайт в браузере.

### Вариант 2. Через PyCharm
1. Откройте **PyCharm**.
2. Выберите **File → Open...** и укажите папку:
   `C:\Users\HONOR\.gemini\antigravity\scratch\lumiere-salon`
3. В правом верхнем углу PyCharm уже готова конфигурация **`Run Server (LUMIÈRE)`**. Нажмите зелёный значок **Play (Run)**.
4. Откройте браузер по адресу:
   - Сайт: [http://localhost:8000](http://localhost:8000)
   - Панель администратора: [http://localhost:8000/admin](http://localhost:8000/admin)

### Вариант 3. Через терминал / PowerShell
```powershell
cd C:\Users\HONOR\.gemini\antigravity\scratch\lumiere-salon
python server.py
```
