# LUMEN — Премиальный Landing Page по Ремонту и Дизайну Квартир

Готовый, высококонверсионный адаптивный сайт под ключ для строительной компании, ремонтной бригады или студии дизайна интерьера.

---

## 🚀 Преимущества и встроенный функционал

1. **Интерактивный калькулятор стоимости ремонта**:
   - Выбор типа объекта (новостройка / вторичка / коттедж).
   - Интерактивный ползунок площади (от 20 до 220 м²) с моментальным пересчетом.
   - Выбор класса отделки (капитальный, дизайнерский, премиум).
   - Дополнительные чекбоксы (дизайн-проект, черновые материалы, умный дом, надзор).
   - Автоматический подсчет итоговой суммы, цены за м², ориентировочных сроков в днях и скидки.
   - Кнопка фиксации расчета с передачей параметров в модальную форму.

2. **Интерактивный Multi-Step Quiz (Опросник)**:
   - 4 пошаговых экрана с анимацией прогресс-бара.
   - Выбор типа недвижимости, метража и сроков.
   - Сбор контактов (телефон, выбор мессенджера: WhatsApp / Telegram / Звонок).

3. **Интерактивный слайдер «До и После» (Before/After Slider)**:
   - Управление мышью на ПК и пальцем (Touch) на смартфонах.
   - Переключение объектов и стилей (нео-минимализм, современная классика, таунхаус).

4. **Пакеты и тарифы**:
   - «Комфорт», «Дизайнерский» (хит продаж) и «Премиум / Люкс».

5. **Интеграция с Telegram-ботом**:
   - Заявки могут приходить мгновенно в ваш Telegram-чат!

6. **Social Proof (Всплывающие уведомления)**:
   - Реалистичные всплывающие уведомления о действиях пользователей на сайте, повышающие доверие.

7. **Адаптивность 100%**:
   - Идеально отображается на смартфонах (iPhone / Android), планшетах и широкоформатных мониторах.

## ⚙️ Быстрая настройка за 1 минуту (`js/config.js`)

Чтобы сменить телефон, название компании, город или подключить Telegram, откройте файл `js/config.js` в любом текстовом редакторе:

```javascript
window.SITE_CONFIG = {
    companyName: "LUMEN GROUP",
    city: "Москва и МО",
    phone: "+7 (495) 890-42-15",
    phoneClean: "+74958904215",
    whatsapp: "74958904215",
    telegramUsername: "lumen_renovate",
    address: "г. Москва, Пресненская наб., 12",
    
    // Telegram-уведомления
    telegram: {
        enabled: true,
        botToken: "ВСТАВЬТЕ_ТОКЕН_БОТА", // Получите в @BotFather
        chatId: "ВСТАВЬТЕ_ВАШ_CHAT_ID"    // Узнайте в @userinfobot
    }
};
```

## 🌐 Как запустить / установить на хостинг

### Вариант 1. Локально на компьютере
Просто дважды кликните по файлу `index.html` — сайт откроется в любом браузере (Chrome, Edge, Safari, Firefox). Никаких серверов устанавливать не нужно!

### Вариант 2. Загрузка на хостинг (Beget, Timeweb, Reg.ru, cPanel)
1. Зайдите в панель управления вашего хостинга.
2. Откройте «Файловый менеджер» и перейдите в папку сайта (обычно `public_html` или `httpdocs`).
3. Загрузите все файлы из архива в эту папку.
4. Готово! Сайт сразу работает.
